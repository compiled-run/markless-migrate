			<h1>x-model</h1>
			<p><code>x-model</code> allows you to bind the value of an input element to Alpine data.</p>
			<p>Here's a simple example of using <code>x-model</code> to bind the value of a text field to a piece of data in Alpine.</p>
			<pre><code data-theme="github-light" data-lang="alpine" class="torchlight" style="background-color: #fff; --theme-selection-background: #e2e5e9;"><div class="line"><span style="color: #24292E;">&lt;</span><span style="color: #22863A;">div</span><span style="color: #24292E;">{" "}</span><span style="color: #6F42C1;">x-data</span><span style="color: #24292E;">=</span><span style="color: #032F62;">"</span><span style="color: #24292E;">&#123; message: </span><span style="color: #032F62;">''</span><span style="color: #24292E;"> &#125;</span><span style="color: #032F62;">"</span><span style="color: #24292E;">&gt;</span></div><div class="line"><span style="color: #24292E;">{"    <"}</span><span style="color: #22863A;">input</span><span style="color: #24292E;">{" "}</span><span style="color: #6F42C1;">type</span><span style="color: #24292E;">=</span><span style="color: #032F62;">"text"</span><span style="color: #24292E;">{" "}</span><span style="color: #6F42C1;">x-model</span><span style="color: #24292E;">=</span><span style="color: #032F62;">"</span><span style="color: #24292E;">message</span><span style="color: #032F62;">"</span><span style="color: #24292E;">&gt;</span></div><div class="line">{" "}</div><div class="line"><span style="color: #24292E;">{"    <"}</span><span style="color: #22863A;">span</span><span style="color: #24292E;">{" "}</span><span style="color: #6F42C1;">x-text</span><span style="color: #24292E;">=</span><span style="color: #032F62;">"</span><span style="color: #24292E;">message</span><span style="color: #032F62;">"</span><span style="color: #24292E;">&gt;&lt;/</span><span style="color: #22863A;">span</span><span style="color: #24292E;">&gt;</span></div><div class="line"><span style="color: #24292E;">&lt;/</span><span style="color: #22863A;">div</span><span style="color: #24292E;">&gt;</span></div><div aria-hidden="true" hidden tabindex="-1" style="display: none;" class="torchlight-copy-target">{"\n<div x-data=\"{ message: '' }\">\n    <input type=\"text\" x-model=\"message\">\n\n    <span x-text=\"message\"></span>\n</div>"}</div></code></pre>
			<div class="demo">
				<div>
					{" "}
					<input type="text" placeholder="Type message..." />
					{" "}

				</div>

			<p>Now as the user types into the text field, the <code>message</code> will be reflected in the <code>&lt;span&gt;</code> tag.</p>
			<p><code>x-model</code> is two-way bound, meaning it both "sets" and "gets". In addition to changing data, if the data itself changes, the element will reflect the change.</p>
			<p>We can use the same example as above but this time, we'll add a button to change the value of the <code>message</code> property.</p>
			<pre><code data-theme="github-light" data-lang="alpine" class="torchlight" style="background-color: #fff; --theme-selection-background: #e2e5e9;"><div class="line"><span style="color: #24292E;">&lt;</span><span style="color: #22863A;">div</span><span style="color: #24292E;">{" "}</span><span style="color: #6F42C1;">x-data</span><span style="color: #24292E;">=</span><span style="color: #032F62;">"</span><span style="color: #24292E;">&#123; message: </span><span style="color: #032F62;">''</span><span style="color: #24292E;"> &#125;</span><span style="color: #032F62;">"</span><span style="color: #24292E;">&gt;</span></div><div class="line"><span style="color: #24292E;">{"    <"}</span><span style="color: #22863A;">input</span><span style="color: #24292E;">{" "}</span><span style="color: #6F42C1;">type</span><span style="color: #24292E;">=</span><span style="color: #032F62;">"text"</span><span style="color: #24292E;">{" "}</span><span style="color: #6F42C1;">x-model</span><span style="color: #24292E;">=</span><span style="color: #032F62;">"</span><span style="color: #24292E;">message</span><span style="color: #032F62;">"</span><span style="color: #24292E;">&gt;</span></div><div class="line">{" "}</div><div class="line"><span style="color: #24292E;">{"    <"}</span><span style="color: #22863A;">button</span><span style="color: #24292E;">{" "}</span><span style="color: #6F42C1;">x-on</span><span style="color: #24292E;">:</span><span style="color: #6F42C1;">click</span><span style="color: #24292E;">=</span><span style="color: #032F62;">"</span><span style="color: #24292E;">message </span><span style="color: #D73A49;">=</span><span style="color: #24292E;">{" "}</span><span style="color: #032F62;">'changed'"</span><span style="color: #24292E;">&gt;Change Message&lt;/</span><span style="color: #22863A;">button</span><span style="color: #24292E;">&gt;</span></div><div class="line"><span style="color: #24292E;">&lt;/</span><span style="color: #22863A;">div</span><span style="color: #24292E;">&gt;</span></div><div aria-hidden="true" hidden tabindex="-1" style="display: none;" class="torchlight-copy-target">{"\n<div x-data=\"{ message: '' }\">\n    <input type=\"text\" x-model=\"message\">\n\n    <button x-on:click=\"message = 'changed'\">Change Message</button>\n</div>"}</div></code></pre>

			<h2 id="modifiers">
				<a href="#modifiers">Modifiers</a>
			</h2>
			<h3 id="lazy">
				<a href="#lazy">
					<code>.lazy</code>
				</a>
			</h3>
			<p>On text inputs, by default, <code>x-model</code> updates the property on every keystroke. By adding the <code>.lazy</code> modifier, you can force an <code>x-model</code> input to only update the property when user focuses away from the input element.</p>
			<p>This is handy for things like real-time form-validation where you might not want to show an input validation error until the user "tabs" away from a field.</p>
			<pre><code data-theme="github-light" data-lang="alpine" class="torchlight" style="background-color: #fff; --theme-selection-background: #e2e5e9;"><div class="line"><span style="color: #24292E;">&lt;</span><span style="color: #22863A;">input</span><span style="color: #24292E;">{" "}</span><span style="color: #6F42C1;">type</span><span style="color: #24292E;">=</span><span style="color: #032F62;">"text"</span><span style="color: #24292E;">{" "}</span><span style="color: #6F42C1;">x-model</span><span style="color: #24292E;">.</span><span style="color: #6F42C1;">lazy</span><span style="color: #24292E;">=</span><span style="color: #032F62;">"</span><span style="color: #24292E;">username</span><span style="color: #032F62;">"</span><span style="color: #24292E;">&gt;</span></div><div class="line"><span style="color: #24292E;">&lt;</span><span style="color: #22863A;">span</span><span style="color: #24292E;">{" "}</span><span style="color: #6F42C1;">x-show</span><span style="color: #24292E;">=</span><span style="color: #032F62;">"</span><span style="color: #24292E;">username.</span><span style="color: #005CC5;">length</span><span style="color: #24292E;">{" "}</span><span style="color: #D73A49;">&gt;</span><span style="color: #24292E;">{" "}</span><span style="color: #005CC5;">20</span><span style="color: #032F62;">"</span><span style="color: #24292E;">&gt;The username is too long.&lt;/</span><span style="color: #22863A;">span</span><span style="color: #24292E;">&gt;</span></div><div aria-hidden="true" hidden tabindex="-1" style="display: none;" class="torchlight-copy-target">{"\n<input type=\"text\" x-model.lazy=\"username\">\n<span x-show=\"username.length > 20\">The username is too long.</span>"}</div></code></pre>
			<h3 id="change">
				<a href="#change">
					<code>.change</code>
				</a>
			</h3>
			<p><code>.change</code> syncs the data only when the input loses focus and its value has changed (the native <code>change</code> event). This is functionally equivalent to <code>.lazy</code>.</p>
			<pre><code data-theme="github-light" data-lang="alpine" class="torchlight" style="background-color: #fff; --theme-selection-background: #e2e5e9;"><div class="line"><span style="color: #24292E;">&lt;</span><span style="color: #22863A;">input</span><span style="color: #24292E;">{" "}</span><span style="color: #6F42C1;">type</span><span style="color: #24292E;">=</span><span style="color: #032F62;">"text"</span><span style="color: #24292E;">{" "}</span><span style="color: #6F42C1;">x-model</span><span style="color: #24292E;">.</span><span style="color: #6F42C1;">change</span><span style="color: #24292E;">=</span><span style="color: #032F62;">"</span><span style="color: #24292E;">username</span><span style="color: #032F62;">"</span><span style="color: #24292E;">&gt;</span></div><div aria-hidden="true" hidden tabindex="-1" style="display: none;" class="torchlight-copy-target">{"\n<input type=\"text\" x-model.change=\"username\">"}</div></code></pre>
			<h3 id="blur">
				<a href="#blur">
					<code>.blur</code>
				</a>
			</h3>
			<p><code>.blur</code> syncs the data when the input loses focus, regardless of whether the value has changed.</p>
			<pre><code data-theme="github-light" data-lang="alpine" class="torchlight" style="background-color: #fff; --theme-selection-background: #e2e5e9;"><div class="line"><span style="color: #24292E;">&lt;</span><span style="color: #22863A;">input</span><span style="color: #24292E;">{" "}</span><span style="color: #6F42C1;">type</span><span style="color: #24292E;">=</span><span style="color: #032F62;">"text"</span><span style="color: #24292E;">{" "}</span><span style="color: #6F42C1;">x-model</span><span style="color: #24292E;">.</span><span style="color: #6F42C1;">blur</span><span style="color: #24292E;">=</span><span style="color: #032F62;">"</span><span style="color: #24292E;">email</span><span style="color: #032F62;">"</span><span style="color: #24292E;">&gt;</span></div><div aria-hidden="true" hidden tabindex="-1" style="display: none;" class="torchlight-copy-target">{"\n<input type=\"text\" x-model.blur=\"email\">"}</div></code></pre>
			<h3 id="enter">
				<a href="#enter">
					<code>.enter</code>
				</a>
			</h3>
			<p><code>.enter</code> syncs the data when the user presses the Enter key. This is useful for search fields where you want to trigger an action only when the user explicitly submits.</p>
			<pre><code data-theme="github-light" data-lang="alpine" class="torchlight" style="background-color: #fff; --theme-selection-background: #e2e5e9;"><div class="line"><span style="color: #24292E;">&lt;</span><span style="color: #22863A;">input</span><span style="color: #24292E;">{" "}</span><span style="color: #6F42C1;">type</span><span style="color: #24292E;">=</span><span style="color: #032F62;">"text"</span><span style="color: #24292E;">{" "}</span><span style="color: #6F42C1;">x-model</span><span style="color: #24292E;">.</span><span style="color: #6F42C1;">enter</span><span style="color: #24292E;">=</span><span style="color: #032F62;">"</span><span style="color: #24292E;">search</span><span style="color: #032F62;">"</span><span style="color: #24292E;">&gt;</span></div><div aria-hidden="true" hidden tabindex="-1" style="display: none;" class="torchlight-copy-target">{"\n<input type=\"text\" x-model.enter=\"search\">"}</div></code></pre>
			<blockquote>
				<p>Note: <code>.enter</code> does not prevent the default behavior. If the input is inside a form, the form will still submit.</p>
			</blockquote>

			<h3 id="number">
				<a href="#number">
					<code>.number</code>
				</a>
			</h3>
			<p>By default, any data stored in a property via <code>x-model</code> is stored as a string. To force Alpine to store the value as a JavaScript number, add the <code>.number</code> modifier.</p>
			<pre><code data-theme="github-light" data-lang="alpine" class="torchlight" style="background-color: #fff; --theme-selection-background: #e2e5e9;"><div class="line"><span style="color: #24292E;">&lt;</span><span style="color: #22863A;">input</span><span style="color: #24292E;">{" "}</span><span style="color: #6F42C1;">type</span><span style="color: #24292E;">=</span><span style="color: #032F62;">"text"</span><span style="color: #24292E;">{" "}</span><span style="color: #6F42C1;">x-model</span><span style="color: #24292E;">.</span><span style="color: #6F42C1;">number</span><span style="color: #24292E;">=</span><span style="color: #032F62;">"</span><span style="color: #24292E;">age</span><span style="color: #032F62;">"</span><span style="color: #24292E;">&gt;</span></div><div class="line"><span style="color: #24292E;">&lt;</span><span style="color: #22863A;">span</span><span style="color: #24292E;">{" "}</span><span style="color: #6F42C1;">x-text</span><span style="color: #24292E;">=</span><span style="color: #032F62;">"</span><span style="color: #D73A49;">typeof</span><span style="color: #24292E;"> age</span><span style="color: #032F62;">"&gt;&lt;/span</span><span style="color: #B31D28;">&gt;</span></div><div aria-hidden="true" hidden tabindex="-1" style="display: none;" class="torchlight-copy-target">{"\n<input type=\"text\" x-model.number=\"age\">\n<span x-text=\"typeof age\"></span>"}</div></code></pre>
			<h3 id="boolean">
				<a href="#boolean">
					<code>.boolean</code>

			<h3 id="debounce">
				<a href="#debounce">
					<code>.debounce</code>
				</a>
			</h3>
			<p>By adding <code>.debounce</code> to <code>x-model</code>, you can easily debounce the updating of bound input.</p>
			<p>This is useful for things like real-time search inputs that fetch new data from the server every time the search property changes.</p>
			<pre><code data-theme="github-light" data-lang="alpine" class="torchlight" style="background-color: #fff; --theme-selection-background: #e2e5e9;"><div class="line"><span style="color: #24292E;">&lt;</span><span style="color: #22863A;">input</span><span style="color: #24292E;">{" "}</span><span style="color: #6F42C1;">type</span><span style="color: #24292E;">=</span><span style="color: #032F62;">"text"</span><span style="color: #24292E;">{" "}</span><span style="color: #6F42C1;">x-model</span><span style="color: #24292E;">.</span><span style="color: #6F42C1;">debounce</span><span style="color: #24292E;">=</span><span style="color: #032F62;">"</span><span style="color: #24292E;">search</span><span style="color: #032F62;">"</span><span style="color: #24292E;">&gt;</span></div><div aria-hidden="true" hidden tabindex="-1" style="display: none;" class="torchlight-copy-target">{"\n<input type=\"text\" x-model.debounce=\"search\">"}</div></code></pre>
			<p>The default debounce time is 250 milliseconds, you can easily customize this by adding a time modifier like so.</p>
			<pre><code data-theme="github-light" data-lang="alpine" class="torchlight" style="background-color: #fff; --theme-selection-background: #e2e5e9;"><div class="line"><span style="color: #24292E;">&lt;</span><span style="color: #22863A;">input</span><span style="color: #24292E;">{" "}</span><span style="color: #6F42C1;">type</span><span style="color: #24292E;">=</span><span style="color: #032F62;">"text"</span><span style="color: #24292E;">{" "}</span><span style="color: #6F42C1;">x-model</span><span style="color: #24292E;">.</span><span style="color: #6F42C1;">debounce</span><span style="color: #24292E;">.</span><span style="color: #6F42C1;">500ms</span><span style="color: #24292E;">=</span><span style="color: #032F62;">"search"</span><span style="color: #24292E;">&gt;</span></div><div aria-hidden="true" hidden tabindex="-1" style="display: none;" class="torchlight-copy-target">{"\n<input type=\"text\" x-model.debounce.500ms=\"search\">"}</div></code></pre>
			<h3 id="throttle">
				<a href="#throttle">
					<code>.throttle</code>
				</a>
			</h3>
			<p>Similar to <code>.debounce</code> you can limit the property update triggered by <code>x-model</code> to only updating on a specified interval.</p>
			{" "}
			<input type="text" />
			{" "}
			<p>The default throttle interval is 250 milliseconds, you can easily customize this by adding a time modifier like so.</p>
			<pre><code data-theme="github-light" data-lang="alpine" class="torchlight" style="background-color: #fff; --theme-selection-background: #e2e5e9;"><div class="line"><span style="color: #24292E;">&lt;</span><span style="color: #22863A;">input</span><span style="color: #24292E;">{" "}</span><span style="color: #6F42C1;">type</span><span style="color: #24292E;">=</span><span style="color: #032F62;">"text"</span><span style="color: #24292E;">{" "}</span><span style="color: #6F42C1;">x-model</span><span style="color: #24292E;">.</span><span style="color: #6F42C1;">throttle</span><span style="color: #24292E;">.</span><span style="color: #6F42C1;">500ms</span><span style="color: #24292E;">=</span><span style="color: #032F62;">"search"</span><span style="color: #24292E;">&gt;</span></div><div aria-hidden="true" hidden tabindex="-1" style="display: none;" class="torchlight-copy-target">{"\n<input type=\"text\" x-model.throttle.500ms=\"search\">"}</div></code></pre>
			<h3 id="fill">
				<a href="#fill">
					<code>.fill</code>
				</a>
			</h3>
			<p>By default, if an input has a value attribute, it is ignored by Alpine and instead, the value of the input is set to the value of the property bound using <code>x-model</code>.</p>
			<p>But if a bound property is empty, then you can use an input's value attribute to populate the property by adding the <code>.fill</code> modifier.</p>
			<div>
				{" "}
				<input type="text" value="This is the default message." />
				{" "}
			</div>
