Conduit (RealWorld): a migration to Markless

The Angular RealWorld frontend, ported to Markless with @markless/migrate and Claude Code, and checked route by route against the original. Both apps use the same RealWorld backend (Nitro, Prisma, SQLite), so their API calls are compared request for request.
