Acme Dashboard: a migration from Next.js to Markless

The final example of the Next.js App Router course (vercel/next-learn, NextAuth sign-in, Postgres, invoice CRUD, search, pagination), ported to Markless and proven with @markless/migrate: 30 of 30 route checks green, signed in and signed out, with every accepted difference listed in the report.

  • The front door: every route is switched to the Markless app; anything else still goes to the old app
  • The old app (Next.js 16, unchanged source)
  • The new app (Markless 0.4.0)
  • The check report: every route, old against new, as anonymous and signed in

Demo login: user@nextmail.com / 123456 (the course's seed user). A session from one app works in the other.

No hosted database was available to this demo, so each app runs a seeded Postgres (PGlite) inside its serverless function. Data starts from the course's seed whenever a new function instance starts: invoices you create or edit stay only while that instance lives, and two instances do not see each other's changes. The dashboard overview shows the data as it was at build time, as the Next.js app prerenders it.
