TanStack Query kitchen sink: a migration to Markless

TanStack Router's kitchen-sink-react-query-file-based example (React, TanStack Router, TanStack Query), ported to Markless 0.9.0 with @markless/migrate and Claude Code, and checked route by route against the original: invoices and users behind a delayed mock API, mutations that invalidate and refetch, search params, prefetch on hover, and clicks faster than the network.

  • The old app (React 19, TanStack Router 1.170, TanStack Query 5.104)
  • The new app (Markless 0.9.0)
  • The check report: every route, old against new

The old app keeps its data in the browser tab; the port keeps one store per tab on its server, in the memory of the function instance that answers. On Vercel a later request can reach another instance, which starts that tab over.
